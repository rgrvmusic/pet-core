Polyend Tracker replay routine
==============================


This is a replay routine for Polyend Tracker projects based on [`tracker-lib`](https://github.com/polyend/tracker-lib) and adjusted for use with [`tracker-ce`](https://github.com/polyend/tracker-ce) projects.
It is an independent project and does not use code from the firmware project and is available as MIT-licensed.

Currently used by 
 - [PT Player](https://itchio.rgrv.nl/ptplayer-web)
 - [PT Player for borg on drumlogue](https://rgrvdotnl.itch.io/ptplayer-drumlogue)

Release will follow soon.
